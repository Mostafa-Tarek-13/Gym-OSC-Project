# Gym / Fitness Class Booking API

This repository contains the scaffold for a Node.js, TypeScript, and Express API for managing gym class bookings.

## Project structure

- src/app.ts
- src/server.ts
- src/config/
- src/controllers/
- src/middleware/
- src/models/
- src/routes/
- src/services/
- src/utils/
- src/docs/

## Planned stack

- Node.js
- TypeScript
- Express.js
- MongoDB + Mongoose
- JWT authentication
- Swagger documentation
- Render / Railway deployment

## Setup

1. Install dependencies with npm.
2. Copy .env.example to .env and configure values.
3. Start development mode using the provided scripts.

## Notes

This is a scaffold only. Application logic will be added in subsequent development stages.
